# Connect Hub

A Flutter social media application with Firebase backend.

## Features
- Email/password and Google authentication
- Create posts with text and images
- View and interact with posts (like, comment)
- User profile showing personal posts
- AI-powered chatbot for post ideas
- Clean architecture with separation of concerns
- Bloc/Cubit state management

## Technologies
- Flutter & Dart
- Firebase (Auth, Firestore)
- ImgBB (image hosting)
- flutter_bloc
- flutter_dotenv
- google_sign_in
